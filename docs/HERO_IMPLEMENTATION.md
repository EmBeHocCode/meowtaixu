## Scene and motion

One lazy React Three Fiber Canvas lives inside Hero, not across the whole site. `HeroWorld` places texture planes at z=-6 (far), -4 (moon), -1 (mid), 0 (fog), 1.5 (near) and 2 (second fog). Plane scaling preserves cover composition at each depth. This is actual depth-based perspective parallax, not several flat CSS backgrounds moving in lockstep.

The camera smoothly damps toward pointer offsets of at most 0.12 / 0.055 world units; no pointer camera motion on touch/mobile. Early scroll can move it forward by at most 0.12 and down 0.06 units and add only 0.07 fog opacity. No pinning, timeline-driven About transition or scroll hijacking is added. Mountains and pavilion have no independent oscillation. Fog gently drifts over long cycles. Only 26 muted-gold specks on desktop / 8 on mobile float slowly; no bloom/postprocessing/particle explosion.

Existing video timing and failure paths are untouched. `entered` from AppShell triggers a 1.6-second HTML content fade with brief blur and a 2.4-second generated-mist reveal. Static image layers are present immediately; optional WebGL loads only after the preloader completes and crossfades in after textures resolve. The readable Hero never waits on Canvas.

## Performance and fallback

Desktop WebP assets total 637,348 bytes; mobile total 579,220 bytes (excluding HTTP overhead and the existing loading video). Alpha is preserved. No runtime PNG masters or new external fonts are requested. System Georgia/Times-style serif and system sans avoid new font downloads.

Canvas uses demand rendering driven at a target of 30 updates/second desktop and 20 mobile, with DPR capped at 1.5 desktop / 1 mobile. It stops scheduling frames when Hero is outside the viewport or the document is hidden. No React state updates run per frame. GPU textures/geometry/materials are managed by R3F/Drei; the shared texture cache is intentionally retained for this single scene. Device performance has been checked in browser viewport emulation, not benchmarked on physical phones.

Reduced motion disables the video per existing behavior, the WebGL scene, Hero reveal animation and Lenis; the complete static layered composition and all HTML controls remain. The same static layers are always behind WebGL, so a lazy import/texture/render failure, unavailable WebGL or lost context does not leave an empty background. Context loss was injected and verified in the test tab, then cleared by reload.

## ImageGen prompts (exact)

Each call used the approved mountain PNG as a style reference and `transparent_background: true`.

Match exactly the reference midnight blue/ink-black rock textures, subtle painterly Chinese ink wash blended with realistic fantasy. Transparent background with genuine alpha. Landscape 16:9. Only a rugged mountain mass growing from the bottom-right edge, highest crags in the right third around 35 percent down, falling lower toward the center-bottom. Left half and upper third entirely transparent so future text and sky remain unobstructed. Detailed silhouette and dark blue-gray stone, not a black flat cutout. No sky, no moon, no background mountains, no opaque fog background, no frame, text, UI, geometric substitutes or logos. Bottom and right rock may reach canvas edges; top silhouette must be cleanly isolated.
